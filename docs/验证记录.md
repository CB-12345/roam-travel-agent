## 真实提供方验证

[首轮四城记录](../evals/live-matrix-initial-report.json) 保留原始结果：成都低预算、北京人文游、广州远期天气通过；杭州两日游失败。杭州失败原因是早餐选到 10:00 开门的餐厅，后端完整停留检查拒绝提交，没有展示一份时间冲突的行程。

本轮修正是在餐厅候选落地时先核对已匹配 POI 的常规营业规则与正常用餐窗口；缺失或复杂规则仍标为未知，不由模型猜测。每餐最多新增核对 8 个不同候选，已查询资料复用缓存；没有合适门店时保留明确的区域建议。

[杭州复测记录](../evals/live-recheck-report.json) 单独保留生成和修改结果。四城共执行 5 次真实生成与 1 次修改，含首次杭州失败，不能描述为首轮 100% 成功；也不能将少量方便样本当成跨城市成功率。通过表示独立规则无硬错误，未知营业、预约等仍是待确认项。

先前 [揭阳单次生成记录](../evals/live-smoke-report.json) 为一次成功观测，耗时 95.74 秒；浏览器在生成中刷新后取回同一任务。统计仅覆盖后台任务，不能据此声称平均性能、费用或成功率。

## 可复现运行与界面

从实际 Git 暂存区导出独立源码副本，不包含 `.env`、`.venv`、本地数据、日志或 Git 元数据。另建虚拟环境，按 `requirements-dev.txt` 与 `requirements.lock.txt` 从头安装成功，`pip check` 无依赖冲突。在该源码副本和新环境中，144 项 Python 测试、7 项前端测试和 20 项离线质量案例再次全部通过。

该副本使用空模型/地图/天气凭证启动于本地独立端口，确认健康状态未启用实时提供方；示例读取、备份导入、独立行程检查，以及首页和全部页面资源均通过 HTTP 验收。验证完成后已停止此临时服务。原有已配置的本地应用、Key 和个人任务数据保留。
